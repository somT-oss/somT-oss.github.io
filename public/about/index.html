About.

Hey, I’m Somto — a Software Engineer focused on Cloud DevOps and Backend systems. I’m based in Nigeria and I spend most of my time building things that (hopefully) don’t break in production.

I work at the intersection of infrastructure and backend engineering — Kubernetes, CI/CD pipelines, distributed systems, and all the fun stuff that happens between writing code and having it actually run reliably at scale.

The “wannabe cracked dev” part is genuine. I think the best engineers are always in a permanent state of not knowing enough, and that’s the part I find exciting.

What I Work With

  • Cloud & Infra: AWS, GCP, Kubernetes, Terraform, Docker
  • Backend: Go, Python, Node.js
  • DevOps: GitHub Actions, ArgoCD, Prometheus, Grafana
  • Databases: PostgreSQL, Redis, MongoDB
